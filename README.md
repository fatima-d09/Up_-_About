# Up & About🚪

**A walkable, multi-floor elevator game** · built over 5 months

A cosy, walkable building of games, music and a disco. Plain HTML, CSS and (mostly) JavaScript: no build step, no libraries, no React.

### [▶ Play the game](https://fatima-d09.github.io/Up_-_About/)

---

## Project files

| File | What it does |
| --- | --- |
| `index.html` | The page |
| `css/style.css` | The designs |
| `js/core.js` | Drawing helpers, characters, saving |
| `js/world.js` | Floors, walking, the elevator |
| `js/rooms.js` | The look of each floor |
| `js/games.js` | Tic-Tac-Toe, Connect 4, Uno |
| `js/boardgames.js` | Snakes & Ladders, Property Parade |
| `js/music.js` | Beats, your own songs, YouTube |
| `js/main.js` | Menus, input and the game loop |
